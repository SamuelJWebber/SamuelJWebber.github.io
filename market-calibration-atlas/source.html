START WITH THE SNAPSHOT

Inspect, reproduce, extend

  1. Download and verify the code. Extract the ZIP, open a terminal in that folder and run:
    python scripts/check_source_bundle.py --directory .
  2. Restore the published chart data. These commands verify downloaded hashes and serve the website locally:
    python scripts/restore_public_data.py --prefix dist/data/
python -m http.server 8000 --directory dist

    Open http://localhost:8000. This runs the existing results; it does not recompute the studies.

  3. Recompute a specific result. Read the study’s instructions, restore its required inputs and run its analysis script. Record the source snapshot, data hashes, dependency versions and exact command.
  4. Make a reviewable proposal. Use the report template and contribution guide. Explain the original result, your change and its effect on the same sample. A local Git repository or your own hosted fork can produce a patch.

FIND THE ASSUMPTION

The most useful things to challenge

What was knowable?

Was the quote recorded before the result was public? Does the clock describe the economic period, release, trading close or settlement? Did revised data enter an earlier forecast?

What actually qualified?

Are missing prices, stale quotes, wide spreads and untraded listings excluded visibly? Are matched horizons comparing the same contracts?

How much evidence is independent?

Many strike prices can settle on one release. Check event weighting, uncertainty, correlated outcomes, exploratory comparisons and whether improvements survive later data.
