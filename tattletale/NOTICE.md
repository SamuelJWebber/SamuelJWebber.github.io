# TattleTale NYC — third-party components

- PP-OCRv4 text detection and recognition models from PaddleOCR (Apache License 2.0), via the @gutenye/ocr-models package (MIT).
- ONNX Runtime Web (MIT License), Microsoft.
- exifr (MIT License).
- NYC street centerline (CSCL) from the NYC Department of City Planning, via NYC Open Data.
